# 和队友一起玩

OpenSquad 目前只支持 Minecraft Java 版的本地或私人服务器。机器人和你一样需要登录并加入服务器，可以在同一台电脑运行，也可以连接你有权限使用的私人服务器。首次体验建议用新的测试存档，先站到机器人附近发几条指令。

## 指令和资源名称

每条消息用 `!bot` 开头，也可以用机器人的实际游戏角色名加冒号，例如 `OpenSquad: 跟着我`。正版登录账号和角色名不一定相同，以游戏里显示的名字为准。默认私人服务器里的玩家都能指挥它；如果只想让自己和指定朋友使用，在 `.env` 填入 `ALLOWED_PLAYERS=你的角色名,朋友的角色名`，其他玩家的消息会被忽略。

常用中文资源不必刻意加空格：`!bot 收集橡木3个`、`!bot 帮我收集3个橡木` 和 `!bot 给我3个泥土` 都可以。数量只写一次，使用大于零的阿拉伯数字；原来的空格写法和英文指令仍保留。其他物品的英文名称需要加空格，例如 `!bot 给我 music_disc_13`。重复数量、零或负数会得到修改提示，不会打断正在执行的任务。

每条消息以 `!bot` 开头，也可以写 `OpenSquad: 过来`。机器人会忽略没叫它的消息。`.env` 的 `ALLOWED_PLAYERS` 可填写允许指挥它的玩家名，用英文逗号分隔；留空时，同服所有玩家都能发指令。离线服的玩家名不是身份认证，请把服务器限制在可信的本地环境。

| 中文              | 英文                         | 用法                     |
| ----------------- | ---------------------------- | ------------------------ |
| `跟着我`          | `follow me`                  | 跟随发指令的人           |
| `过来`            | `come here`                  | 走到发指令时你的位置     |
| `停下`            | `stop`                       | 中断当前动作和持续模式   |
| `状态`            | `status`                     | 查看当前任务或持续模式   |
| `背包`            | `inventory`                  | 查看携带的物品和数量     |
| `收集 橡木 3`     | `collect oak_log 3`          | 收集额外的 3 个原木      |
| `给我 橡木 3`     | `give me oak_log 3`          | 投放背包里已有的物品     |
| `保护我`          | `protect me`                 | 跟随你并攻击附近敌对生物 |
| `攻击`            | `attack nearby hostile mobs` | 攻击机器人附近敌对生物   |
| `记住 我喜欢挖矿` | `remember I like mining`     | 保存你主动告诉它的偏好   |
| `回忆`            | `memory`                     | 查看自己的偏好和近期合作 |
| `忘记我`          | `forget me`                  | 清除自己的记录           |
| `帮助`            | `help`                       | 查看常用指令             |

支持采集的资源名称如下。木材按原木计算，粗铁来自铁矿石，圆石来自石头或圆石；机器人不会自动烧炼或合成。

| 中文名称           | 游戏中的英文名称 |
| ------------------ | ---------------- |
| 橡木、橡木原木     | `oak_log`        |
| 白桦木、白桦木原木 | `birch_log`      |
| 云杉木、云杉木原木 | `spruce_log`     |
| 泥土               | `dirt`           |
| 沙子               | `sand`           |
| 圆石               | `cobblestone`    |
| 煤炭               | `coal`           |
| 粗铁               | `raw_iron`       |
| 钻石               | `diamond`        |

数量默认是 1，一次采集默认最多 16 个，搜索范围默认 32 格。一块矿石可能掉多个物品，因此实际数量可能略多。找不到足够资源时，机器人会报告实际收集量；一个也没拿到则明确提示未完成，不会写入成功记录。发出另一条动作指令前，等它完成或者先说 `停下`；跟随和保护会持续运行，新的动作可以替换这些模式。

忙碌或收尾时也可以问 `帮助`、`状态`、`背包` 和 `回忆`，不会中断动作、调用模型或新增合作记录。状态显示正在处理的指令或已开启的持续模式，不代表它每一刻都在移动或已经接近目标。背包按物品种类合并数量，一次展示前八种，其余只提示种类数；常用资源显示中文名，其他物品保留游戏中的英文名称。

交付物品通过投放完成。站在机器人附近把东西丢给它，它捡到后就能使用或交回。交付时其他玩家和生物也可能捡走掉落物。普通移动不会挖路，采集时只允许挖取所请求资源对应的方块，仍可能影响附近同类建筑材料。

取回装备可以说 `!bot 给我石镐`、`!bot 给我铁剑` 或 `!bot 给我盾牌`；照明和食物可以说 `!bot 给我火把8个`、`!bot 给我3个面包`。支持木、石、铁、金、钻石和下界合金材质的镐、斧、铲、剑，以及火把、面包、苹果、牛排、盾牌、铁锭和木棍，背包中也显示这些中文名称。其他物品仍可用英文物品名，例如 `!bot 给我 music_disc_13`。这些名称不会扩大采集范围，工具和食物需要先放进机器人的背包。

跟随和保护会暂停等待暂时不可见的玩家；同名玩家回到可见范围后会继续，不必再发一次指令。保护模式追击结束后会回到跟随，目标没变时保留原来的寻路任务。它不会跨维度或传送来找你，复杂地形仍可能阻挡路线。

战斗出手前会检查到目标躯干的视线。墙体等碰撞方块挡住时不会只因为距离近就攻击；视线经过的区块没有加载时也会等待。它仍使用基础追击路线，不保证能绕过复杂障碍，也没有自动回血或盾牌策略。

基础聊天不需要模型密钥，支持简单的固定问法，例如 `!bot 你好`、`!bot 你能做什么`、`!bot 今天做什么`、`!bot 你记得我的偏好吗` 和 `!bot 上次一起做了什么`。活动建议参考最近保存的偏好，合作回顾只读取已保存的事件。聊天建议不会执行动作，也不会创建普通聊天记录；不认识的问法会提示当前范围，开放式对话需要配置外部模型。

叫停会等当前动作的收尾完成，再确认已经停止。超时后也会先收尾，这段时间新的动作会被拒绝，避免上一件事干扰下一件事。如果底层动作一直没有结束，机器人可能持续提示忙碌；重新连接可以恢复，不能把“超时”理解成已经保证完成了停止。

机器人死亡后会取消原来的任务和持续模式，重生后会提醒你重新发出指令。重新生成角色期间不接新指令；旧任务或聊天稍后结束时，不会再发出过期回复，也不会补写成功记录。普通动作仍须等收尾完成才能接新任务；记忆文件中已保存的记录会保留。本地连接检查已覆盖死亡、重生后查看记忆和重新跟随，正式 Java 服务器中的物品掉落与完整重生体验仍需实玩验证。

## 连接不上怎么办

首次配置可以运行 `npm run setup`，按中文提示填写服务器信息。已有 `.env` 时它不会改写文件。需要生成默认的本机配置，可运行 `npm run setup -- --defaults`；端口仍需与你的服务器一致。

`npm run doctor` 会先检查配置和记忆文件，再尝试连接端口。它不会登录 Minecraft、调用模型或显示密钥。端口能连接只说明网络通了，游戏版本、账号权限和白名单需要实际进服后确认。

如果启动或检查时提示某个配置项不正确，按提示修改 `.env` 后重试，例如 `MC_PORT` 必须是 1 到 65535 之间的整数。如果提示记忆文件损坏或无法读取，先停止机器人并备份 `MEMORY_PATH` 指定的文件，再修复格式、调整权限，或把 `MEMORY_PATH` 改为一个新的文件位置。换用新文件会从空记忆开始，旧记录仍在原文件及备份里；程序不会替你覆盖或删除它。

如果提示连接被拒绝，确认服务器已启动，并核对地址和端口；“对局域网开放”的端口每次都可能不同。如果提示版本不兼容，把 `MC_VERSION` 设为服务器的准确版本，或留空自动检测，所用版本还必须被当前 Mineflayer 支持。自动检查使用 1.18.2，其他版本不等于已经验证。

需要正版认证的服务器要使用 `MC_AUTH=microsoft`，机器人账号必须拥有 Java 版、能完成登录，并在服务器白名单内。不要把自己的登录凭据贴到 Issue。被踢出或断线后，机器人目前不会自动重连，修正问题再重启。

如果已入服却提示看不到你，先走近它并让周围区块加载。采集矿石失败时，检查它是否有能挖该矿的镐，是否存在可走的路线，以及背包是否已满。有限动作默认 45 秒超时，超时会尝试停止动作并给出反馈。
