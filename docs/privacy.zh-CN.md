# 隐私与记录

保存或删除记录失败时，机器人不会确认成功，会保留原有数据并提示检查本地存储权限和空间；修复后需要重新发指令。游戏动作已经完成、但合作记录保存失败时，会分别报告动作结果和记录失败，不会因此取消跟随等持续模式。这些游戏内存储错误提示不包含本机文件路径。

OpenSquad 没有分析统计、录音或屏幕采集。基础模式不请求外部模型。Minecraft 连接会向你指定的服务器发送玩家身份和游戏操作；游戏内回复出现在服务器聊天频道，同服玩家及服务器日志可能看到这些消息。

机器人只在你使用 `记住` 时保存偏好，并记录成功协作动作的结果。每名玩家最多保留 20 条偏好和 50 条带时间的事件，存放在本机 `data/memory.json`。普通自由聊天不写入这份文件。模型会获得的上下文和本机保存的记忆是两件事：启用外部模型后，你发给机器人的自由聊天、玩家名、偏好和近期事件会发送到 `.env` 指定的模型服务；动作指令不调用模型。

使用 `!bot 忘记我` 或 `!bot forget me` 可以删除当前玩家的本地记录。它不会清除其他玩家的记录，也不会删除 Minecraft 服务器日志、备份或模型服务已收到的数据。清空所有玩家记录时，先停止机器人，再删除自己配置的记忆文件；不要在机器人运行中手动修改它。

`.env`、记忆文件、日志及本地认证缓存不应上传到 GitHub。`.gitignore` 已覆盖默认位置；如果把 `MEMORY_PATH` 指到自定义路径，需要把对应路径加入忽略规则。发布问题反馈前，检查日志里是否有服务器地址、账号和凭据。GitHub 的公共账号名和仓库地址是项目发布身份，不属于运行记录。

本项目用于私人或本地服务器。允许指挥的名单按游戏中的玩家名匹配，在离线服中不能防止他人冒用名字。自己的 Minecraft 服务器和模型服务如何保存数据，还取决于各自配置与政策。
